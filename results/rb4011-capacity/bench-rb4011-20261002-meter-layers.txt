# Conclusions (f = frame incl FCS):
#   /interface bytes, switch-chip bytes, monitor-traffic (Winbox graphs) = f        (L2 with FCS)
#   ethernet driver-*-byte, sniffer size, traffic-gen packet-size           = f - 4    (L2 without FCS)
#   btest throttle (local/remote-tx-speed, *-udp-tx-size)                   = f - 18   (IP packet, L3)
#   btest tx/rx-total-average                                               = f - 46   (UDP payload, L4)
#   wire / line rate                                                        = f + 20   (preamble + IFG, L1)
#   A VLAN tag is frame bytes in every L2 meter (+4 per tag).

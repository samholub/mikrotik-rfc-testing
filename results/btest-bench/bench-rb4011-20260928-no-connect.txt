Load   : Brief, 20 Mbps, 70 B only
Why    : code review finding - the script never reads btest's status, so a test that
         never connects may be reported as a dead circuit.

Result : Finding confirmed. btest does not raise an error in either case: the do={} callback

         does not catch it either. The ping in the callback still succeeds (0.3 ms),
         so the block shows a live path with no traffic.
         Rule and script removed afterwards.
